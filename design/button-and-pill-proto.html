二 · 选中态的边怎么画

现在是 1 px 深色描边配 999 px 圆角。125% 缩放下那 1 px 落到 1.25 个物理像素上，圆弧两端一个像素深、一个像素浅，就成了锯齿。与其调描边参数，不如换一种选中画法。五版都是未选中在左、选中在右。

S1 · 现在：1 px 深色描边

纸白 暖砂

inset 0 0 0 1px var(--text)

S2 · 深色实心，字反白

纸白 暖砂

background: var(--accent)

S3 · 浅底，不画边

纸白 暖砂

background: var(--active)

S4 · 描边 + 淡底

纸白 暖砂

1px var(--text-dim) + var(--panel)

S5 · 现在 + 常驻图层

纸白 暖砂

translateZ(0)
