把 Pi 搬到中心那台机器上：会话、工作区、Pi 子进程都在中心，PC 和手机打开的是同一份。
这是第一个发布版本，界面与体验还会继续改。

## 新功能

- **中心与桌面客户端**：中心一个进程管会话库与全部 Pi 子进程，客户端只是那一页界面；
  同一个会话被 PC 和手机同时打开时共用一个 Pi 子进程，事件广播给所有客户端。
- **对话管理**：新建、重命名、删除、按日期分组的列表，标题在第一句发出后自动生成；
  删除只清中心的记录，不碰 Pi 自己的会话文件。
- **输入**：`@` 补全工作区文件（选到目录会接着往下钻），`/` 列出 Pi 里的命令、提示词模板与技能，
  图片可以粘贴也可以直接拖进窗口。
- **消息**：流式输出、工具调用折叠、代码块一键复制、整个对话导出成 Markdown。
- **模型**：按当前会话切模型和思考等级，用量与压缩入口在头部。
- **常驻**：`start-center.ps1` 后台起中心，`install-autostart.ps1` 让中心跟着登录自动启动。

完整实现与验收记录见 [进度记录](https://github.com/huaxianyan/SevenStation/blob/v0.3.0/docs/STATUS.md)。
