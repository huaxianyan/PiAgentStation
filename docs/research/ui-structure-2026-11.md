# 界面结构：抄什么、不抄什么

2026-11-17。选型前的调研结论，落地后作为改界面的参照。

## 参考对象

`Vochsel/pi-web`（同步把 Pi 的 RPC 事件映射成聊天流，靠 SSE 转发到浏览器）的结构可以照搬：

| 它的组件 | 对应的东西 |
| --- | --- |
| `chat-shell.tsx` | 整页骨架：会话容器 + 消息滚动区 + 输入区，滚动条贴底逻辑 |
| `chat-message.tsx` | 一条消息按 content block 拆：正文、思考、工具、图片 |
| `ai-elements/reasoning.tsx` | 思考块折叠，默认收起，正文在下方 |
| `ai-elements/tool.tsx` | 工具卡片：状态图标 + 工具名 + 参数摘要 + 可展开的输入输出 |
| `ai-elements/prompt-input.tsx` | 输入区：多行文本、回车发送、附件、发送与停止同键 |
| 它的会话层 | 一个会话一个 Pi 子进程，按会话 id 复用 |

它没有侧栏（只服务单会话）。侧栏与按工作目录分组是本项目补的，参照主流聊天客户端的列表形态。

```text

│ 筛选会话     ├──────────────────────────────────────────────┤
│              │                                              │
│ ▸ ws         │           ┌──────────────────┐               │
│   · 会话一   │           │ 用户消息（右对齐）│               │
│   · 会话二   │           └──────────────────┘               │

│   · 会话三   │  ▸ 思考（折叠）                               │
│              │  ┌ 工具卡片：状态 名称 参数摘要 耗时 ─────┐   │

└──────────────┴──────────────────────────────────────────────┘
```

## 定下来的几条

- 内容列固定 820 px 居中。宽屏留白比拉长行宽更容易读。
- 助手消息不套气泡，用户消息才套。两者的区分靠对齐，不靠两种底色。
- 思考块默认收起，流式期间标题写「正在思考」，收尾后变「思考」。
- 工具卡片默认收起，头部一行放状态、工具名、参数摘要与耗时，正文放参数与输出。
- 输入区在流式期间同一个按钮变「停止」，回车改为插入引导消息（steer）。
- 扩展的 `setStatus` 落侧栏底部，`setWidget` 落输入区上方的窄条。阻塞式弹窗走居中模态。
