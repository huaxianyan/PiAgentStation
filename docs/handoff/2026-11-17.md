# 交接：Pi 桌面界面第一版

2026-11-17。给下一个接手的人：读完这页可以直接接着干。

## 当前状态

- 远端 `git@github.com:huaxianyan/PiAgentStation.git`（公开），分支 `main`；本地克隆路径见 `AGENTS.md`。
- 结构是「中心 + 客户端」：`src/MAStation/` 管 Pi 子进程与会话，兼管前端托管；
  `src/PiAgentStation.Desktop/` 只是 WebView2 壳。前端只有一份，在 `Server/wwwroot/`。
- 构建与运行：`pwsh -File scripts/dev-run.ps1`。它先起中心（默认 `127.0.0.1:8787`），再起客户端，
  并带 9222 调试端口。
- 冒烟验证：`node scripts/ui-smoke.mjs --cwd <已存在目录>`，会真的调一次模型。
- 运行日志：`%LOCALAPPDATA%\PiAgentStation\logs\app.log`。

## 本轮完成

- 宿主：WPF 窗口 + WebView2（虚拟域名 `app.local` 指向 `wwwroot`），关窗时先关子进程 stdin 再退出。
- RPC 桥：一条命令一个相关响应，超时可配；事件原样转发；子进程退出与 stderr 尾部回传界面。
- 会话：按磁盘扫描会话列表（同时支持默认的分目录布局和 `--session-dir` 的扁平布局），
  按工作目录分组，点击可续聊；新建会话走系统目录选择框。
- 对话：流式正文、思考块折叠、工具卡片（状态、参数摘要、耗时、参数与输出）、
  流式期间按钮变「停止」、回车插入引导消息。
- 扩展：`setStatus` 落侧栏底部，`setWidget` 落输入区上方，`notify` 落右下角提示，
  `select` / `confirm` / `input` / `editor` 走居中模态。
- 顶部：模型下拉、思考等级、上下文用量、压缩按钮。

02:34 在 `gdi32full.dll` 里崩过一次（`0xc0000409`，BEX64）。用户指认是本机 MacType
（字体渲染注入）造成的，不是代码问题。调试期间给 PiAgentStation 关掉 MacType 或加白名单，
再遇到先排除这一项，别急着查代码。

## 下午的结构调整：拆成中心 + 客户端

- 触发：用户说明目标形态是一套中心负责与 Pi 交互，PC 与手机都连这套中心；日后客户端再加 host
  能力去操作别的设备。原「只做 PC 端」的约束作废，记在 `docs/DECISIONS.md` 的 D1–D3。
- 落地：`AppBridge` 变成 `CenterHub`，命令应答回发起连接、会话事件广播给所有连接；
  `Rpc/` 与 `Sessions/` 迁到服务端；桌面端删掉了起进程与扫会话的代码，只剩加载中心地址；
  前端从 `chrome.webview` 桥换成 `/ws?token=`。
- 新建会话不再调用桌面端原生目录对话框（那选的是客户端机器的路径），改成界面里填中心机器的路径，
  并给出最近用过的几个目录。
- 验证（同日，真窗口 + CDP + 第二个 WebSocket 客户端）：
  - 冒烟脚本通过：连接状态「已连接」、新会话、流式、收尾、侧栏刷新。
  - 第二个客户端 `list_sessions` 拿到同一份会话，`open_session` 拿到 3 条历史。
  - 桌面窗口发一条消息，第二个客户端收到同一条 `text_delta` 与 `agent_settled`，key 一致。
  - 同一会话打开两次只产生 1 个 key，即只有一个子进程。
- 新增的坑：缺 `app.UseWebSockets()` 会导致前端一直停在「正在连接」；`Start-Process` 不能把
  stdout 与 stderr 重定向到同一文件；PowerShell 5.1 读无 BOM 的 UTF-8 脚本会把中文注释解错。

## 下一步建议

1. 手机端可用：现在只是同一页面能在手机上打开，要按窄屏调整侧栏与输入区。
2. 中心常驻：开机自启或做成 Windows 服务，客户端地址配置支持远程（现在读
   `%LOCALAPPDATA%\PiAgentStation\center.json`）。
3. 局域网访问与 TLS：要用前先跟用户确认授权范围，发布说明里写清风险。
4. 做 `@文件` 补全：中心加 `list_dir`，界面加补全弹层，验收用「打 `@` 能看到中心机器上的文件」。
5. 做会话重命名与删除，验收用「改名后侧栏和磁盘文件都对，删掉的会话不再出现在列表」。
6. 出第一次打包产物，按 `RELEASE.md` 的两个包与校验和走一遍。
