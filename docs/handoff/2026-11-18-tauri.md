# 改名 Seven Station、桌面壳换 Tauri（2026-11-18 凌晨）

## 一句话

产品与仓库改名 Seven Station：中心变 `SevenStation.Core`（Host），桌面客户端从 WPF + WebView2 换成
Tauri 2（Rust + WebView2），页面上的自绘窗口按钮取消，窗口交给系统标题栏。Host 里加了 Agent 名片
与能力表，Pi 是第一个、现在也是唯一的一个实现。

## 做完的

**改名**

- 仓库 `huaxianyan/PiAgentStation` → `huaxianyan/SevenStation`（GitHub 保留旧地址重定向），
  remote 已改成新地址。
- `src/MAStation` → `src/SevenStation.Core`，命名空间、程序集、exe 名一起换。
- 数据目录从 `%LOCALAPPDATA%\MAStation` 换成 `%LOCALAPPDATA%\SevenStation`，按用户要求不迁移，
  旧目录留着不动即可。环境变量 `MASTATION_*` → `SEVENSTATION_*`。
- 页面 localStorage 键 `piagentstation.*` → `sevenstation.*`。
- 脚本、README、AGENTS.md、RELEASE.md、发布说明模板里的名字与路径都跟着换。

**桌面壳换 Tauri**

- `src/SevenStation.Desktop` 现在是 Cargo 项目（`cargo build` 出 `sevenstation-desktop.exe`），
  WPF 的 csproj 与 XAML 已删除。
- 壳负责：读 `center.json` + `token.txt` 拼带令牌的地址、加载中心页面、记忆窗口位置（`window.json`）、
  离线页（`dist/index.html`，连不上时显示）、日志（`logs/client.log`）、单实例、系统选目录。
- 壳的命令：`pick_folder`（系统文件夹对话框）、`center_local`（中心是否在本机）。
  中心页面是远端来源，要在 `capabilities/center.json` 里放开 `remote.urls`，
  自定义命令要在 `build.rs` 的 `AppManifest::commands` 里登记，否则报 not allowed。
- 页面里：窗口按钮、拖动区、`has-window-chrome` 样式全部删掉；选目录改成
  `window.__TAURI__.core.invoke('pick_folder')`，失败再退回页面里的目录树。

**Host 的 Agent 边界（第一步）**

- `Agents/AgentDescriptor.cs`：`AgentCapabilities`（工具、思考等级、模型、上下文用量、压缩、扩展、
  技能、命令、附件）+ `AgentDescriptor`（id、名称、版本、是否就绪、能力表、信息行）+ `AgentRegistry`。
- `Agents/PiAgent.cs`：Pi 的版本、程序目录、会话目录、能力声明都在这里，Pi 专属信息不再散在 Host 里。
- 协议 `hello` 里 `pi` 换成 `agent`（主 Agent id）与 `agents`（名片数组）；设置页的 Agent 卡片
  按名片的信息行渲染；思考等级与模型面板按能力表决定显不显示。

## 没做完的

  用 robocopy `/MOVE` 搬了 5.4 GB。旧目录 `E:\Dev\PiAgentStation` 变成空壳，还被当前这个 shell 的
  工作目录占着，删不掉，重启或关掉会话后 `rmdir` 一下即可。
- **Host 里的 Pi 会话生命周期还没收进 `IAgentRuntime`**：现在 `CenterHub` 仍然直接 `PiSession.Start`，
  名片与能力表这一层已经落地，但"多个 Agent 实现"还只有一层皮。
- 系统选目录只验证到"对话框能开、能取消、不崩"，真选一个目录回填的链路还没走通（自动化点不动系统对话框）。
- 发布打包脚本已改成 `cargo build --release` 取单个 exe，但还没真跑一遍出包。
