两个包的第一版：Seven Station Core 把 Pi 挪到一台常驻的机器上跑，Seven Station 客户端在别的设备上连过来看到同一份。只发 Windows x64 包。

## 新功能

- **常驻服务**：Seven Station Core 装成 Windows 服务 `SevenStationCore`，跑在系统账户下，开机自动启动；默认只监听 `127.0.0.1:8787`，访问要带令牌，令牌在 `%ProgramData%\SevenStation.Core\token.txt`。
- **对话库**：会话按工作目录分组、按日期排列；标题在第一句发出后自动生成；改名与删除只动 Seven Station Core 的记录，不碰 Pi 自己的会话文件。
- **一处会话多处看**：同一个会话被多个客户端打开时共用一个 Pi 子进程，正文、思考、工具调用广播给所有连接。
- **像样的对话界面**：流式正文与思考块、工具调用卡片、文件浏览、终端、导出、搜索、`@` 补全、切模型与思考等级、上下文用量与压缩。
- **设置页**：外观（明暗与四套配色）、Seven Station Core 地址与版本、Pi 的版本与目录、最近工作区、快捷键、自定义样式、运行日志，改完所有设备一起生效。
- **客户端首启引导**：没配置过的设备先填 Seven Station Core 地址与访问令牌，测通才进得去；填错令牌与地址不通分别说清是哪一种。

Seven Station Core 以后会出 Linux 包，这版只提供 Windows x64。

完整实现与验收记录见 [进度记录](https://github.com/huaxianyan/SevenStation/blob/v0.3.0/docs/STATUS.md)。
