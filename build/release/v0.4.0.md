这版把 Seven Station Control 装进 Seven Station Core 的安装包，安装程序换了自己的画面，产品名统一。两个包都是 Windows x64。

## 新功能

- **Seven Station Control 随 Seven Station Core 一起装**：开停服务、看运行日志、改监听地址、查看访问地址与令牌，都在一个窗口里。关掉窗口只是收进托盘，服务照常跑；退出走托盘右键。
- **局域网连接开关**：打开时按提示放行防火墙，只对本地子网开放；访问地址显示真实内网 IP，不再是 `0.0.0.0`。
- **安装向导有自己的画面**：顶栏、侧图、图标都是 Seven Station 自己的，「应用和功能」和开始菜单里也是同一枚图标；完成页可以直接打开 Seven Station Control。
- **命名统一**：面向用户的文字只写 Seven Station Core、Seven Station Control 与 Seven Station，不再出现「中心」「控制台」这类译名。

## 问题修复

- **同版本重装不换文件**：Windows Installer 原来会因为文件版本号相同跳过替换，现在每次构建都带新的文件版本号，覆盖装必定换到新文件。

两个包都可以覆盖装：Seven Station Core 的数据在 `%ProgramData%\SevenStation.Core`，客户端的连接信息在 `%LOCALAPPDATA%\SevenStation\center.json`，配置、令牌、对话库都保留。

完整实现与验收记录见 [进度记录](https://github.com/huaxianyan/SevenStation/blob/v0.4.0/docs/STATUS.md)。
